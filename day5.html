01Networking Deep Dive

Networking Fundamentals

Every cloud network is built from the same primitives you'd find in a physical data center.

LAN

A local network under one administrative domain — your VCN behaves like a private LAN.

WAN

Networks spanning locations, connected over long-distance links — the internet is the largest WAN.

Packet Switching

Data is broken into packets, each routed independently and reassembled at the destination.

Switching vs Routing

Switching moves frames within a network by MAC address; routing moves packets between networks by IP address.

Network Security Groups apply rules to specific VNICs, not entire subnets — much finer-grained.

Security ListsNSGs
ScopeEntire subnetIndividual VNICs

10VCN Architecture

VCN Architecture Concepts

A Virtual Cloud Network is your private, software-defined network inside OCI.

VCN

A private network with its own CIDR block, isolated from other tenancies.

Subnet

A subdivision of the VCN's CIDR, regional or AD-specific, public or private.

VNIC

A virtual network interface attached to a compute instance, carrying its private (and optionally public) IP.

DHCP Options / DNS Labels

Control internal DNS resolution and hostname assignment within the VCN.

15Compute

Compute Architecture & Shapes

OCI compute ranges from shared VMs to bare metal dedicated purely to you.

Virtual Machine

Shares physical hardware with other tenants via the hypervisor. Fast to provision, flexible shapes.

Bare Metal

An entire physical server dedicated to you — no hypervisor overhead, full hardware access.

Dedicated Host

A physical server reserved for your VMs only — isolation without going fully bare metal.

GPU / HPC Shapes

Specialized shapes for ML training or tightly-coupled HPC workloads with cluster networking.

20Storage

Storage Overview

Four storage types, each solving a different access pattern.

📦 Object Storage

HTTP-accessible, unlimited scale, for unstructured data — backups, media, logs.

💽 Block Storage

Raw attached volumes for compute instances — boot volumes and data volumes.

📁 File Storage

Shared NFS filesystem, mountable by multiple instances at once.

🗄 Archive Storage

Lowest cost, retrieval takes hours — for long-term compliance retention.

Keeps prior versions of an object when overwritten — protects against accidental deletes.

Lifecycle Policies

Automatically transitions or deletes objects by age — e.g. move to Archive after 90 days.

Pre-Authenticated Requests

Cheat Sheets

VCN & CIDR

  • VCN CIDR: /16 to /30
  • /24 = 254 usable hosts
  • Route tables use longest-prefix-match

Gateways

  • IGW = public inbound+outbound
  • NAT = private outbound only
  • SGW = private access to OCI services (no internet)

Security

  • Security Lists = subnet-wide, stateful
  • NSGs = per-VNIC, finer-grained
  • Both apply simultaneously if both are attached

Compute & Storage

  • cloud-init runs once, on first boot
  • Object = HTTP; Block = attached; File = shared NFS
  • Terraform provisions, Ansible configures
