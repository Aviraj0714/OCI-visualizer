29Certification Center

Final Revision Cheat Sheets

Governance

  • Compartments isolate; Policies authorize; Tags classify
  • Quotas = self-imposed; Limits = provider ceiling
  • Org Management links billing, not IAM

Cost

  • Right-size on actual utilization, not guesses
  • Idle resources are the fastest, safest savings
  • Commitments trade flexibility for discount at scale

Security & Compliance

  • Security posture = IAM + Vault + Cloud Guard + Logging combined
  • Security Zones block; Cloud Guard detects+responds
  • Map each framework to concrete technical controls, not just a checkbox

Operations

  • Terraform provisions; Ansible configures
  • Always validate DR with an actual failover test
  • Executive dashboards roll up governance+security+cost+compliance+availability+ops
